# Changelog

All notable changes to this project are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). There are no tagged
releases.

## [Unreleased]

### Changed

- Licence changed from MIT to Apache-2.0 from this version on.

### Added

- Repository documents: CLAUDE.md, CONTRIBUTING, SECURITY, code of conduct,
  issue and pull request templates, documentation index.

### Fixed

- README no longer advertises an npm package that is not published, nor tool
  memory that the plugin does not return.

## 1.0.1 - 2026-01-27

### Changed

- Plugin renamed from `clawdbot` to `memos-memory` to match the plugin id.
- README installation commands updated.

## 1.0.0 - 2026-01-26

### Added

- Initial MemOS memory plugin: `memory_search`, `memory_save` and `memory_get`
  tools over the MemOS REST API.
